# Моя Зарплата — расчетный листок и AI-ассистент

Одностраничное приложение (`index.html`, без сборки) для учета смен, питания персонала
(-50% от стоимости) и премий с автоматическим расчетом аванса и зарплаты.

## Возможности

- **Меню сверху слева** — все функции приложения собраны в одном выпадающем меню:
  AI-ассистент, экспорт PDF, тема оформления, настройки AI, сброс данных.
- **Календарь смен** — часы и такси по каждому дню, разделение на аванс и зарплату.
- **Питание персонала** — покупки с автоматическим удержанием 50%.
- **Премии** — с привязкой к авансу или зарплате.
- **PDF-отчет** — расчетная ведомость формата A4 с печатью.
- **AI-ассистент** — понимает команды на русском и узбекском:
  - смены: `1,2,5-9 по 12 часов`, `с 1 по 15 по 8 ч без такси`
  - удаление: `удали смены 3,4`
  - питание: `сегодня купил обед за 620`, `вчера 2 шт по 300 сум`
  - премии: `премия 5000 за качество`
  - настройки: `ставка 350`, `такси 200`, `аванс 25 числа`
  - расчеты и аналитика: `когда зарплата?`, `статистика за месяц`
  - любое изменение можно откатить кнопкой «Отменить»

## Режимы AI

- **Локальный** (по умолчанию) — встроенный движок разбора команд, работает без интернета.
- **Gemini** — в «Меню → Настройки AI» добавляется ключ Google Gemini API; включает
  свободные вопросы и распознавание фото графика смен. Ключ хранится только в
  `localStorage` браузера и никуда больше не передается.

Все данные хранятся локально в браузере (`localStorage`).
