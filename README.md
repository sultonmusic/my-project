# Моя Зарплата — расчетный листок и AI-ассистент

Одностраничное приложение для учета смен, питания персонала, премий и автоматического расчета аванса и зарплаты.

## Возможности

- Календарь смен, часы и такси по каждому дню.
- Питание персонала с удержанием 50%.
- Премии, больничные и расчет выплат.
- PDF-отчет формата A4.
- Локальный AI-ассистент на русском и узбекском.
- **GitHub Cloud Sync** — данные синхронизируются между устройствами через `data/cloud-data.json`.

## GitHub Cloud Sync

Нажмите синюю кнопку с облаком в правом нижнем углу. Укажите:

1. GitHub fine-grained personal access token с доступом только к репозиторию `sultonmusic/my-project` и разрешением **Contents: Read and write**.
2. Пароль шифрования длиной не менее 8 символов.

Репозиторий публичный, поэтому данные перед отправкой шифруются в браузере с помощью AES-256-GCM. Ключ получается из пароля через PBKDF2-SHA256 (250 000 итераций). Токен и пароль не записываются в исходный код; токен хранится только до закрытия вкладки. Без пароля расшифровать облачный файл невозможно.

Приложение продолжает использовать локальную копию как рабочий кэш, а после подключения каждая правка автоматически отправляется в GitHub. При входе с другого устройства введите тот же токен и пароль — последняя версия загрузится из GitHub.

> Никогда не добавляйте GitHub token прямо в файлы репозитория.
